# Create Pull Request

Create a pull request for the completed work on branch `{{FEATURE_BRANCH}}`.

## Instructions

1. **Analyze the changes:**
   ```bash
   git log {{BASE_BRANCH}}..HEAD --oneline
   git diff {{BASE_BRANCH}}...HEAD --stat
   ```

2. **Review the Board context** to understand the plan intent and completed tasks.

3. **Create the PR** using `gh pr create` with:
   - A clear, concise title (not just the plan name)
   - A description that explains:
     - What was implemented/changed
     - Why these changes were made
     - How to test the changes

## PR Format

```bash
gh pr create --title "feat: <clear description>" --body "$(cat <<'EOF'
## Summary

<2-3 sentences explaining what this PR does>

## Changes

<Bullet list of key changes>

## Test Plan

<How to verify these changes work>

---
Generated by [Ralph](https://github.com/arvesolland/ralph)
EOF
)"
```

Create the PR now.
